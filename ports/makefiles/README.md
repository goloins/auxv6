# auxv6 Port Makefiles

Put per-port auxv6 makefiles in this directory using:

name.Makefile

Example:

icewm.Makefile

The sync helper copies this file to the downloaded source tree as:

Makefile.auxv6

in:

ports/<source_dir>/Makefile.auxv6

See `ports/ports.list` for manifest format and port class selection.
