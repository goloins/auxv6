# base32(1)

## Name
base32 - Base32 encode or decode.

## Synopsis
```
base32 [-d] [file ...]
```

## Description
Encodes input using RFC 4648 Base32 by default. With `-d`, decodes input.

## Options
- `-d`, `--decode` - Decode instead of encode.
