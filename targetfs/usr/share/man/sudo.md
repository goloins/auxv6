# sudo(1)

## Name
sudo - Compatibility alias for asroot.

## Synopsis
```
sudo command [args ...]
```

## Description
In auxv6 this command is a symlink to `asroot(1)`.

## Notes
- Minimal behavior only.
- Requires an already-root shell.

## Source Audit
- Symlink target: /bin/asroot
- Last updated: 2026-04-06
