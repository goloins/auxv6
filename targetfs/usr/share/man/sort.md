# sort(1)

## Name
sort - Sort text lines.

## Synopsis
```
sort [-n] [-r] [file ...]
```

## Description
Reads lines from files (or standard input) and writes sorted output.

## Options
- `-n` - Numeric sort by leading signed integer.
- `-r` - Reverse sort order.
