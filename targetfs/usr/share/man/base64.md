# base64(1)

## Name
base64 - Base64 encode or decode.

## Synopsis
```
base64 [-d] [file ...]
```

## Description
Encodes input using RFC 4648 Base64 by default. With `-d`, decodes input.

## Options
- `-d`, `--decode` - Decode instead of encode.
