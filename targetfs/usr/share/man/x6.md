# x6

## NAME
x6 - minimal phase-1 display-server scaffold for auxv6

## SYNOPSIS
`x6 [-f] [-p port]`

## DESCRIPTION
`x6` is an initial phase-1 userspace display-server scaffold used to begin
the X11 bring-up path for a future dwm session.

Current scope is intentionally narrow:

- claim and release display ownership through `/proc/server7`
- bind a loopback TCP endpoint
- expose a simple line-oriented control protocol for bring-up tests
- maintain a tiny in-memory window table (`CREATE`, `MAP`, `CONFIGURE`, etc.)

This is not a full X11 implementation yet. It is a stepping stone for protocol,
session, and lifecycle validation.

## OPTIONS
- `-f` run in foreground (no daemonize)
- `-p port` listen port (default: `6006`)

## PROTOCOL (PHASE 1)
On connection, x6 sends:

`X6/1 READY`

Supported client commands:

- `HELLO x6/1`
- `PING`
- `CREATE <id> <x> <y> <w> <h>`
- `MAP <id>`
- `UNMAP <id>`
- `CONFIGURE <id> <x> <y> <w> <h>`
- `DESTROY <id>`
- `LIST`
- `QUIT`

## EXIT STATUS
- `0` clean shutdown
- non-zero startup or runtime lifecycle failure

## EXAMPLES
Run in foreground:

```sh
x6 -f
```

Run on a custom port:

```sh
x6 -f -p 6010
```
