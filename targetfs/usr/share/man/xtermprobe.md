# xtermprobe(1)

## Name
xtermprobe - interactive xterm/ANSI input and mouse-report probe.

## Synopsis
```sh
xtermprobe [-m 1000|1002|1003] [-e normal|utf8|sgr|urxvt] [-f] [-q] [-d] [-r] [-t] [-T] [-P]
```

## Description
xtermprobe places the terminal in raw mode, enables selected xterm mouse
tracking/encoding modes, then prints each received byte in hex (and printable
ASCII when applicable).

Use it to validate terminal behavior while implementing or debugging:
- modifier key sequences
- mouse tracking modes 1000/1002/1003
- mouse encoding modes 1005/1006/1015
- focus in/out reports (mode 1004)

Press `q` to exit and restore terminal settings.

## Options
- `-m 1000|1002|1003`:
  Select mouse tracking mode.
  - `1000`: X10 press-only tracking
  - `1002`: button-event tracking
  - `1003`: any-event tracking (default)
- `-e normal|utf8|sgr|urxvt`:
  Select mouse encoding.
  - `normal`: classic `ESC [ M`
  - `utf8`: mode 1005 UTF-8
  - `sgr`: mode 1006 SGR (default)
  - `urxvt`: mode 1015 urxvt format
- `-f`:
  Enable focus event reporting (mode 1004).
- `-q`:
  Emit common capability/status queries (`DA`, secondary `DA`, `CPR`) at startup.
- `-d`:
  Decode recognized escape sequences and print interpreted events alongside raw bytes
  (for example SGR mouse press/release, focus in/out, CSI/SS3 key families).
- `-r`:
  Force raw-byte printing (useful with `-d` when you want decoded and raw views together).
- `-t`:
  Run non-interactive self-tests and exit with status 0 on pass, non-zero on failure.
  Self-tests verify DA/CPR replies, mode-query on/off behavior for 1000/1002/1003,
  focus mode 1004, bracketed paste mode 2004, and encoding-mode separation across
  1005/1006/1015.
- `-T`:
  Run a guided focus-transition test for mode 1004 and exit with status 0 on pass.
  This mode waits for both `CSI O` (focus-out) and `CSI I` (focus-in), typically
  generated by switching to another VT and then returning.
- `-P`:
  Run a guided bracketed-paste test for mode 2004 and exit with status 0 on pass.
  This mode waits for a full `CSI 200~ ... CSI 201~` frame and verifies payload bytes
  are present between start and end markers.

## Examples
```sh
# Default: any-event tracking + SGR encoding
xtermprobe

# X10 press-only mouse tracking
xtermprobe -m 1000 -e normal

# Button-event tracking with UTF-8 mouse encoding and focus reports
xtermprobe -m 1002 -e utf8 -f

# Startup query probe + SGR mouse encoding
xtermprobe -q -e sgr

# Raw + decoded event view
xtermprobe -d -m 1003 -e sgr -f

# Non-interactive core protocol checks
xtermprobe -t

# Guided focus transition check (switch away and back between VTs)
xtermprobe -T

# Guided bracketed paste check (paste text into terminal)
xtermprobe -P
```

## Notes
- Requires both stdin and stdout to be TTYs.
- This tool is for protocol observation, not for rendering tests.
